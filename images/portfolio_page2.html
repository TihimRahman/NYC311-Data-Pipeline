Highlights
  • End-to-end ELT: Socrata API → S3 → Snowflake, raw JSON shaped into analytics-ready star schema marts via dbt.
  • 69 dbt tests and typed data contracts that fail the build on schema drift — bad data never reaches BI.
  • Event-driven Airflow Assets decouple extraction from transformation — no polling, no cron coupling.
  • Fully containerized with Docker — one-command, reproducible setup for any developer.
